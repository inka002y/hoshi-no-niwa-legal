星のにわ　プライバシーポリシー

このポリシーは、お子さまとご家庭向けのお絵描きアプリ「星のにわ」で扱う情報について、保護者の方に説明するものです。

アプリ内の情報

アプリはオフラインで遊べます。アカウント登録、広告、利用状況の分析や追跡はありません。描いた線や遊びの内容は端末上で処理し、運営者に送信しません。氏名、連絡先、写真、位置情報などの個人情報をお子さまに入力させたり、アプリから送信させたりする機能はありません。

端末に保存する設定

選んだ庭とモード、音、切替ロックの設定は端末内に保存します。保護者用の番号は照合用の値に変換して保存します。誤入力回数とロックの解除時刻も端末内に保存し、外部リンクや設定の誤操作防止に使います。端末の設定から「アプリを削除」を選ぶと、その端末のアプリデータを削除できます。

お問い合わせ

保護者の方がメールでお問い合わせをした場合、メールアドレスとお問い合わせ内容を、返信と対応に必要な範囲で利用します。メールの送受信にはメールサービスを使います。対応に不要になった情報は、法令上の保存義務や紛争対応で必要な場合を除き、削除します。開示、訂正、削除などのご相談は、下記の窓口で受け付けます。

お子さまの情報

お問い合わせには、お子さまの氏名や写真、保護者用の番号を含めないでください。お子さまの個人情報が誤って送られたと分かった場合は、法令上必要な場合を除き、速やかに削除します。保護者の方は、誤って送った情報の削除を同じ窓口に依頼できます。

公開ページ

アプリ内の本文は、画面上の「？」からオフラインで確認できます。保護者画面から公開ページを選ぶと、端末のブラウザーで開きます。公開ページでは、ホスティングを提供する GitHub がセキュリティのためにアクセス元の IP アドレスを記録します。詳しくは GitHub のプライバシーステートメントをご覧ください。
