星のにわ　プライバシーポリシー

このポリシーは、星のにわで扱う情報と、保護者の方が確認できる方法を説明します。

アプリ内の情報

アプリにアカウント登録、広告、行動追跡、利用状況の分析機能はありません。描いた線や遊びの内容を運営者に送信する機能もありません。保護者用の番号は照合用の値として端末内に保存します。番号の誤入力回数、選んだ庭とモード、音の設定も端末内に保存します。アプリの削除により、端末にあるこれらのアプリデータを削除できます。

お問い合わせ

保護者の方からお問い合わせがあったときは、送信元のメールアドレスとお問い合わせ内容を、対応に必要な範囲で利用します。本文にはお子さまの氏名や写真などを記載しないでください。対応に不要になった情報は、法令上または紛争対応上必要な場合を除き、削除します。開示、訂正、削除などのご相談も、同じ窓口で受け付けます。

公開ページ

保護者画面から公開ページを開くと、端末のブラウザーが GitHub Pages に接続します。アクセスに伴う情報の取り扱いには GitHub のプライバシーステートメントが適用されます。
